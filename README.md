# 导师BTI · 48 题公开版

[在线体验](https://user-test--mentor-bti-feedback-preview-20261006.netlify.app/)

导师BTI是一款面向硕博生的科研生态自测产品。用户完成 48 道题后，可以查看 16 型结果，并在登录后保存结果和提交反馈。这个仓库展示当前已上线的产品流程与实现，适合作为产品设计、增长验证和前后端协作的案例。

## 当前功能

- 首页、科研域与 16 型介绍；48 题答题、结果页和分享入口。
- 邮箱密码注册与登录；登录后答题、查看个人结果和提交反馈。
- 页脚公开展示页面浏览次数、累计注册账户与完成 48 题次数，并提供统计口径说明。页面保持打开时约每 10 秒获取一次最新数字。
- 基于 Supabase 的用户、测试结果、反馈与匿名访问事件存储；Netlify 托管 Next.js 网站。

当前公开仓库只保留上述功能。插画素材尚未确认再发布权利，因此这里使用 CSS 角色占位图；[在线体验](https://user-test--mentor-bti-feedback-preview-20261006.netlify.app/)的视觉素材与此仓库可能不同。本仓库不包含线上用户数据、密钥或第三方服务配置。

## 本地运行

需要 Node.js 22 与 pnpm 11。复制 `.env.example` 为本地 `.env`，填写**你自己的** Supabase 项目地址和密钥，切勿使用线上生产密钥。数据库结构参考 `supabase/migrations`；迁移文件仅作为代码资料，运行或部署前应先在独立测试项目核对。

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm --filter @mentor-bti/web dev
```

未配置 Supabase 时，公开介绍页仍可查看；注册、登录、云端保存、反馈和公开统计需要相应服务配置。部署到 Netlify 时使用仓库根目录的 `netlify.toml`。

## 产品与数据口径

类型是对答题者当前科研互动感知的描述，不是导师能力排名或心理诊断。个人结果仅供登录的答题者查看；公开的 16 型介绍不包含个人结果。

页脚的浏览量是成功保存的产品页面访问**次数**，刷新可能重复计入；完成量是成功保存的 48 题结果**次数**，同一人复测可以多次计入；注册量是 Supabase Auth 中当前仍存在的账户**总数**，包含更早创建的测试账户。这些数字不等于独立访客、实名用户或有效转化人数。浏览量和完成量的起算时间由 `PUBLIC_METRICS_START_AT` 设置。

## 代码结构

| 路径 | 作用 |
| --- | --- |
| `apps/web` | Next.js 页面、账户流程、反馈与统计接口 |
| `packages/bti-content` | 48 题内容与数据校验 |
| `packages/bti-scoring` | 48 题判型逻辑 |
| `packages/bti-core` | 共享数据类型 |
| `supabase/migrations` | 数据结构与访问策略 |
| `tests` | 关键行为测试 |

项目仍处于小范围测试阶段。代码与题目内容的再使用许可、素材授权仍待确定；当前仓库可公开阅读，但尚未授予复制、修改或再分发的开源许可。
